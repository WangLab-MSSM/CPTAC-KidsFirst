Contribute to this project

We welcome contributions from the broader pediatric cancer research community — new pipelines, bug fixes, notebook improvements, or documentation. All code is reviewed by a project maintainer before merging.

1
Fork and clone — git clone https://github.com/WangLab-MSSM/CPTAC-KidsFirst
2
Branch from dev — git checkout -b feature/your-feature
3
Follow the style guide — PEP 8 for Python, tidyverse conventions for R; document with docstrings.
4
Open a pull request — link the relevant issue and tag at least one reviewer from the maintainers list.
5
Add data access notes — if your code needs protected data, document dbGaP accession numbers and consent requirements.
